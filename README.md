# wwl-cbun

Vue 3 widgets for Weekend Web Labs: code editor, draw, hex grid, and music player. Each widget is its own subpath (`/code-editor`, `/draw`, `/hex-grid`, `/music-player`).

Not published. Peer dependency: `vue` >= 3.3. Widgets use `--vd-*` tokens. [Labs](https://github.com/nostromo-618/weekend-web-labs) links `../wwl-cbun` and reads `dist/`.

```bash
pnpm install && pnpm build
```

Demos: https://nostromo-618.github.io/weekend-web-labs/#widgets
